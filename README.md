# NPS ARCN Fire Monitoring Objectives Scripts

This repository contains data management and analytical scripts that fulfill the requirements of the first two out of four fire monitoring objectives described in the Fire Monitoring Protocol for the Arctic Network, National Park Service, Alaska (Barnes et al. 2018). See below for the list of monitoring objects.

These scripts replace SOP 1.8- Fire Extent and Frequency Data Analysis and Reporting. In 2019 the Wildland Fire Application Information Portal (WFMI) fire point database was replaced with InFORM. These scripts serve as a crosswalk to join the old reporting system with the new, so the fire statistics and trends can incorporate the full recorded fire history. The script produces a word document with a series of graphs showing the extent, frequency, and temporal trends of ARCN fires. Written interpretation of these graphs is not part of the 'arcn_objectives' script, but can be added by the PI to the word document for ARCN annual reporting needs.

The arnc_objectives_efn2.4.2026 provides a couple additional graphs that are not included in the original arcn_objectives rmd file and is the most up to date rmd file.

ARCN Fire Monitoring Objectives:
1. Determine the variability and decadal-scale trends in fire frequency (number of fires/year), average fire size, maximum fire size, and total area affected by fire in ARCN network parks.
2. Detect the variability and decadal-scale trends in number of lightning strikes by park and ecoregions for ARCN.
3. Detect decadal-scale trends and variability in burn severity on fires larger than 1000 acres in ARCN.
4. Detect changes in species composition, vegetation structure, and ground cover due to time since fire and burn severity.

Barnes, J. L., J. L. Hrobak, and B. Sorbel. 2018. Fire monitoring protocol for the Arctic Network: Fire extent, severity, and effects. Natural Resource Report NPS/ARCN/NRR—2018/1716. National Park Service, Fort Collins, Colorado.
